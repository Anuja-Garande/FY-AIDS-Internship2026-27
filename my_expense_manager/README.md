# Personal Expense Tracker

## Project Overview

The Personal Expense Tracker is a web-based application developed using PHP, MySQL, Bootstrap 5, HTML, CSS, and JavaScript. It helps users manage their daily income and expenses, categorize transactions, generate reports, and view financial summaries through an easy-to-use dashboard.

---

## Features

- User Registration and Login
- Secure Authentication
- Dashboard with Financial Summary
- Add, Edit, Delete Income
- Add, Edit, Delete Expenses
- Category Management
- Monthly Reports
- Date-wise Report Filter
- Charts using Chart.js
- Profile Management
- Settings Page
- Export Report to Excel (CSV)
- Print / Save Report as PDF
- Responsive Bootstrap 5 Design

## Database Setup

1. Open XAMPP.
2. Start Apache and MySQL.
3. Open phpMyAdmin.
4. Create a database named:

```
my_expense_manager
```

5. Import:

```
my_expense_manager.sql
```

---

## How to Run

1. Copy the project into the XAMPP `htdocs` folder.

Example:

```
C:\xampp\htdocs\my_expense_manager
```

2. Start Apache and MySQL.

3. Open your browser.

4. Visit:

```
http://localhost/my_expense_manager/
```

5. Register a new account and log in.
